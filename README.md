# عالم لوليتا — مشروع Android

## محتويات المشروع
- تطبيق Android أصلي باستخدام Kotlin وJetpack Compose.
- شاشة دخول بكلمة مرور.
- 10 عوالم و100 مفاجأة.
- حفظ حالة المفاجآت المفتوحة محليًا.
- نسخ الرسائل إلى الحافظة.
- تغيير كلمة المرور وقفل التطبيق.

## كلمة المرور الافتراضية
`بحبك ي بابا`

يمكن تغييرها من الإعدادات بعد الدخول. اكتبها بنفس المسافات: بحبك ثم مسافة ثم ي ثم مسافة ثم بابا.

## فتح المشروع وبناء APK
1. ثبّت Android Studio (إصدار حديث).
2. افتح مجلد `Alam_Lolita_Android` في Android Studio.
3. انتظر Gradle Sync حتى يكتمل.
4. من القائمة اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5. ستجد ملف APK عادة في:
   `app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات مهمة
- المشروع مصدر قابل للبناء، وليس ملف APK مبنيًا أو مختبرًا.
- كلمة المرور الحالية بوابة محلية بسيطة وليست حماية تشفيرية؛ محتوى الرسائل مضمن داخل التطبيق ويمكن استخراجه تقنيًا.
- محتوى الفويسات حاليًا عبارة عن نصوص إرشادية لتسجيلها بصوت محمود؛ تسجيل/تشغيل الملفات الصوتية يحتاج إضافة ملفات التسجيل الفعلية في إصدار لاحق.
- التقدم محفوظ محليًا على الجهاز.
- التطبيق لا يرسل رسائل أو بيانات إلى أي خادم.
